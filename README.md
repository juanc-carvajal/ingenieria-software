# Ingeniería de Software

Este repositorio es un recopilatorio de los proyectos desarrollados durante la asignatura de Ingeniería de Software.

## Contenido
- **Practica-1-Ing-Software**: Implementación de una interfaz de gestión de equipos médicos, ubicaciones y personal, con soporte para base de datos SQL.
- **Practica-2-Ing-Software**: Desarrollo de un sistema completo para la gestión de laboratorios, incluyendo una API con Django y un frontend en Vue.js para la gestión de pacientes, laboratoristas y resultados.
- **Practica-3-Ing-Software**: Desarrollo de una API de gestión de equipos médicos utilizando Django en el backend y Vue.js en el frontend, incluyendo la gestión de base de datos SQL.
